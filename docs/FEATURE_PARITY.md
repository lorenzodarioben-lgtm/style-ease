## Explicit migration choices

The new guest is not an account. State persists for the cookie's 30-day lifetime; no cross-device identity or automatic transfer of old localStorage is promised. Delivery details are not collected; sample checkout scenarios replace the original address-shaped demo form. Existing dollar amounts are unchanged and explicitly USD sample values.

Original generated ratings, disconnected famous-brand labels and unsupported performance/quality claims were removed from the new runtime. Original material/option values are clearly sample specifications. Product 19 keeps its ID/price/options with the corrected name Crest Cuff Bracelet. Inherited photos are labelled editorial references throughout; no claim that they depict exact selectable products.

Hash fragments never reach Go. Existing Pages links/storage remain intact at their old origin. Only path aliases can receive an HTTP redirect from Go. Any future old-origin compatibility script requires separately approved deployment.

Advanced Studio drag/reorder/export/public sharing, consumer/admin authentication, arbitrary uploads, real customer reviews, real payments and fulfilment are DEFERRED and have no dead visible controls. The finished private outfit-board minimum is exposed.
